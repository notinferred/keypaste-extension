`chrome.pub` is the Chrome Web Store item's public key, which the store holds the private half of; it is the Chromium manifest's `key`, so an unpacked build carries the store's ID. `edge.pub` is Microsoft Edge Add-ons' public key for keypaste's extension, which that store holds the private half of; it gives the Edge build the ID `src/Keypaste.Core/Browser/BrowserIdentity.cs` names. `node ids.js` prints the extension ID each key gives.
