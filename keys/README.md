`chrome.pub` is the Chrome Web Store item's public key, which the store holds the private half of; it is the Chromium manifest's `key`, so an unpacked build carries the store's ID. `edge.pub` is a test key, the public half of an RSA-2048 pair whose private half was discarded when it was made, which gives the Edge build the test ID `src/Keypaste.Core/Browser/BrowserIdentity.cs` names until Microsoft Edge Add-ons assigns keypaste's extension its own. `node ids.js` prints the extension ID each key gives.
